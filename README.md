# بسته آماده سازی APK برای تقویم شمسی (نسخه آفلاین/محلی)

> 🚀 **ساخت APK با GitHub Actions:** [docs/GITHUB-SETUP.md](docs/GITHUB-SETUP.md) — راهنمای کامل: [docs/BUILD-GUIDE.md](docs/BUILD-GUIDE.md)

این پوشه شامل فایل های لازم برای تبدیل اپ وب تقویم به APK اندرویدی آفلاین است.

## محتویات

```
persian-calendar-apk/
├── README.md                          # این فایل
├── BUILD-GUIDE.md                     # راهنمای جامع ساخت APK (۳ روش)
├── keystore-secrets.txt               # ⚠️ رمزهای کلید امضا (جای امن نگه دارید)
├── twa-config/
│   ├── twa-manifest.json              # پیکربندی نمونه برای Bubblewrap (آفلاین)
│   └── assetlinks-template.json       # الگوی Asset Links
└── source-code/                       # کد منبع پروژه Next.js (برای build)
    ├── .github/workflows/build-apk.yml  # ورک‌فلوی ساخت APK امضاشده
    └── scripts/make-keystore.sh         # اسکریپت ساخت کلید (اگر کلید جدید خواستید)
```

> فایل `my-release.keystore` و نسخه Base64 آن (`my-release.keystore.base64.txt`) جدا از این بسته و جای امن نگه داشته می‌شوند؛ مقادیر موردنیاز GitHub Secrets در `keystore-secrets.txt` هست.

## شروع سریع

### روش توصیه شده: Capacitor (آفلاین کامل)

```bash
cd source-code
npm install

# ویرایش next.config.ts: output: 'export' را اضافه کنید
npm run build

npm install @capacitor/core @capacitor/cli @capacitor/android
npx cap init "Persian Calendar" "com.persiancalendar.app" --web-dir=out
npx cap add android
npx cap copy
npx cap sync
npx cap open android
# در Android Studio: Build > Build APK(s)
```

### روش ساده: PWA روی گوشی

1. اپ را روی localhost اجرا کنید
2. در کروم اندروید باز کنید
3. Add to Home screen

## قابلیت های اپ

- 📱 نویگیشن بار پایین صفحه با ۴ تب: تقویم، یادآورها، یادداشت‌ها، تنظیمات — هدر و نوار پایین ثابت
- 📅 تقویم شمسی-میلادی با نمایش مناسبت ها + کارت «نزدیک‌ترین یادآور» با آیکون دسته و ساعت سررسید
- 🔔 روشن/خاموش کردن نوتیف‌ها فقط با ضربه روی زنگوله بالای صفحه
- 🔔 نوتیفیکیشن بومی اندروید که حتی وقتی اپ بسته‌ست سر وقت می‌آد (آلارم دقیق)
- 🌙 مناسبت های شمسی، قمری و جهانی (قابل فعال/غیرفعال در تنظیمات)
- 🔄 تبدیل تاریخ دو طرفه (داخل تنظیمات)
- 🎂 محاسبه سن دقیق (داخل تنظیمات)
- 📝 یادداشت ها با حالت انتخاب و حذف گروهی
- 👥 دسته‌بندی یادآورها با آیکون مخصوص: تولد، سالگرد، مناسبت، کار، قرار، جلسه، دارو، قسط، قبض، اجاره، چک، بیمه، یادداشت
- 🔔 متن نوتیفیکیشن بر اساس نوع یادآور و ساعت و دقیقه دلخواه
- 🗓️ مناسبت های کامل سال ۱۴۰۵ از Time.ir با رنگ جدا برای هر دسته
- 🔁 تکرار روزانه، هفتگی، ماهانه، هر N روز/هفته/ماه و سالانه؛ چند زمان یادآوری برای هر یادآور
- ✅ دکمه های «انجام شد»، «۱۰ دقیقه بعد» و «۱ ساعت بعد» روی نوتیفیکیشن
- 🏖️ نوتیف مناسبت ها (تعطیلات رسمی، شمسی، قمری، جهانی) با کلید جدا برای هر دسته
- 🌐 به روزرسانی مناسبت ها از اینترنت
- 📌 نوتیف همیشگی «تاریخ امروز» با آیکون عدد روز شمسی
- 📋 همه دراپ‌داون‌ها و انتخاب ساعت/دقیقه درون‌برنامه‌ای (بدون کادر اندروید)
- ✨ اسپلش اسکرین و انیمیشن نرم بین تب ها
- ✏️ ویرایش و حذف یادآورها
- 🎨 رابط کاربری با استایل اپل و تم لایت
- 🔒 کاملاً آفلاین و محلی
